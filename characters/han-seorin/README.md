**얼굴 (오리지널 특징)**

**헤어**

## 3. 이미지 생성

프롬프트 원문과 세팅은 [`prompts.md`](./prompts.md)에 있습니다.

### 캐릭터 일관성 유지 방법
1. **마스터 컷 먼저 확정**: `prompts.md`의 마스터 프롬프트로 여러 장 생성 → 가장 마음에 드는 얼굴 1장을 "기준 얼굴"로 선정.
2. 이후 컷은 그 **생성된 기준 얼굴**을 캐릭터 레퍼런스로 사용 (Midjourney `--oref`, Flux/SDXL의 IP-Adapter FaceID, 또는 기준 이미지 20~30장으로 LoRA 학습).
3. 눈물점·헤어 길이·이어링을 모든 프롬프트에 고정 키워드로 유지.
4. ⚠️ 레퍼런스 사진 속 실존 인물의 얼굴을 얼굴 레퍼런스(face ref)로 넣지 마세요 — 특정인과 닮은 이미지가 되어 초상권 문제가 생길 수 있습니다. 레퍼런스는 **스타일/구도 참고(style ref)** 용도로만 쓰는 것을 권장합니다.
5. SNS 등에 게시할 때는 AI 생성 가상 인물임을 표기하는 것을 권장합니다.
